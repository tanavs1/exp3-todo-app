# Experiment 3 - To-Do List App

A simple to-do list made with HTML, CSS and JavaScript for Web Development Lab (Week 3).

## Features
- Add a new task (button or Enter key)
- Click on a task to mark it as completed
- Delete a task
- Shows how many tasks are completed

## Files
- `index.html` - the page
- `style.css` - styling
- `script.js` - JavaScript code using DOM manipulation
